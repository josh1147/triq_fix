# TriQ / MANGER dependency set
#
# Install with uv:
#     uv venv --python 3.10
#     uv pip install -r requirements.txt
#     uv pip install -r requirements-sc2.txt      # on the training box
#
# ---------------------------------------------------------------------------
# READ THIS BEFORE CHANGING ANY PIN
# ---------------------------------------------------------------------------
# Two things break this codebase on a modern stack, and neither is obvious:
#
#   1. numpy<2 is mandatory.
#      src/components/action_selectors.py does
#          from matplotlib.pyplot import xcorr
#      matplotlib re-exports that name from numpy, and numpy 2.0 deleted
#      np.xcorr. Under numpy>=2 the import raises and every controller import
#      dies, so nothing starts.
#
#   2. collections.Mapping is referenced in src/main.py:
#          if isinstance(v, collections.Mapping):
#      That alias was removed in Python 3.10. As written, the code only runs on
#      3.9. On 3.10+ it raises AttributeError inside recursive_dict_update
#      before any training begins.
#      Run `python check_env.py`; it reports this and tells you the one-line fix
#      (switch to collections.abc.Mapping) if you want to stay on 3.10+.
# ---------------------------------------------------------------------------
# Torch is intentionally unpinned so the CPU-only boxes can install the light
# wheel. On a GPU box, do NOT let the resolver pick: it will grab whatever is
# newest on PyPI, which may be built for a CUDA newer than your driver.
#
# Measured failure on a driver reporting CUDA 12.8 (version 12080):
#   plain `torch`            -> 2.14.1+cu130 -> "driver too old", cuda False
#   --index + cu121          -> silently resolved from PyPI, still cu130
#   --index-url + aliyun     -> 2.5.1+cu121  -> cuda True
#
# So: install torch from a wheel index FIRST, with the version pinned, then
# install this file. Because torch is already satisfied, the resolver leaves it
# alone. The Chinese mirror is much faster than download.pytorch.org:
#
#   uv pip install torch==2.5.1 \
#       --index-url https://mirrors.aliyun.com/pytorch-wheels/cu121/
#
#   uv pip install -r requirements.txt
#
# CPU only:
#   uv pip install torch --index-url https://download.pytorch.org/whl/cpu
# ---------------------------------------------------------------------------
